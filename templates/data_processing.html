02 / Processing

What a retained trial becomes

Each fitting boundary is explicit in the repository.

  1. 01

    Cue-aligned EEG

    B01: C3, Cz and C4; a 3-second segment after each cue.

  2. 02

    Temporal filter bank

    Ten overlapping 8–30 Hz bands, eighth-order zero-phase Butterworth filtering.

  3. 03

    Spatial features

    CSP extreme components and log-normalised variance; {{ split.features }} features with one component per side.

  4. 04

    Detection path

    PCA → PC1 EWMA warning → multivariate Stage-II validation. Fit and evaluation are kept separate.

  5. 05

    Classifier path

    Single or bagged linear SVM on FBCSP features, currently a separate benchmark from CSE-triggered adaptation.

04 / Paper map

What the implementation now establishes

Each completed task is linked to a source and its exact implementation boundary.

01 · Data roles

2A and 2B development partitions

Raza et al. (2019), §§4.1–4.3 ↗ defines dataset-specific sessions and the subsequent 70/30 training/validation partition.

Implemented: 2A split ↗, 2B protocol ↗ and shared splitting.py ↗. Exact random membership was not reported in the paper.
02 · Signal representation

Ten-band FBCSP and PCA

Raza et al. (2019), §§4.2–4.3 ↗ describes the filter bank, CSP variance features and PCA before CSE.

Implemented: bci/fbcsp.py ↗ and development_pipeline.py ↗; validation and evaluation are transformed by training-fitted filters.
03 · Detector

Warning before validation

Raza et al. (2015) ↗ motivates EWMA shift detection; Raza et al. (2019), Algorithm 1 ↗ connects Stage-I warnings to Stage-II confirmation.

Implemented: detection/ ↗ and subject diagnostics. The supplied B01 run differs from the published Table 1 target under that configuration.
04 · Alternate protocol

The 2016 split is a separate experiment

Raza et al. (2016), §§3.1.2 and 3.4 ↗ uses I–II to train, III to choose hyperparameters and IV–V to evaluate.

Conceptually distinguished. The current GDF-only bagging benchmark evaluates on III, so it does not implement that published selection/evaluation sequence.
05 · Classifier comparison

Single versus bagged SVM

Chowdhury et al. (2018) ↗ supplies online linear-SVM adaptation context; Raza et al. (2019) ↗ motivates adaptive ensembles.

Implemented as a separate fixed classifier benchmark ↗. PWKNN pseudo-labels, confirmation-triggered dynamic ensemble growth and the full online feedback system remain outside this result.
