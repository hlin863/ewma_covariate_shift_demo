Online event sequence

Prediction first, adaptation second

The chronological boundary is explicit: the current model predicts before any update triggered at that same trial. A successful update only changes subsequent predictions.

01

Predict

Use the current classifier before revealing or synthesising new training knowledge.

02

Read detector evidence

Record the Stage-I warning and any Stage-II decision available at this trial.

03

Select candidates

Use current_trial, since_last_update or all_seen without admitting the same evaluation observation twice.

04

Pseudo-label

PWKNN returns one label and confidence value for each candidate observation.

05

Gate knowledge

Only candidates strictly above the configured confidence threshold can enter the knowledge base.

06

Retrain

Accepted pseudo-labelled observations grow the training set, increment the classifier version and affect future trials.

Evidence boundary

Implementation evidence is not model-performance evidence

Regression tests establish ordering, label exclusion, confidence gating and duplicate-admission protection. A saved end-to-end dataset run is still required before claiming adaptive benefit on real EEG or predictive-maintenance data.
