    Classification and pseudo-labelling · separate from shift detection

    How does each model make a BCI decision?

    Follow one FBCSP trial through an interpretable tree path, nearest-neighbour evidence, PWKNN confidence and the linear-SVM margin.

    01 · Monitor

    EWMA / Stage I

    Asks whether the monitored feature stream looks unusual.

    02 · Validate

    K-S / Hotelling

    Tests whether a candidate shift has statistical support.

    03 · Decide class

    Tree / KNN / SVM

    Maps one prepared BCI feature vector to left or right motor imagery.

    04 · Acquire knowledge

    PWKNN

    Assigns a pseudo-label plus confidence for transductive adaptation. It is not the same role as the final classifier.

    What becomes a tree node?

    The datasets are not the tree nodes. A subject/session supplies observations. Each observation is an FBCSP feature vector, and the fitted tree learns threshold nodes such as 10_14Hz_csp_high_1 ≤ threshold. A trial follows those thresholds until it reaches a left/right leaf.

    What this means for continual learning

    A detector event can trigger an adaptation policy, but the model that makes the class decision remains replaceable. The repository can therefore compare a transparent tree, KNN or SVM under the same update policy, while PWKNN remains the separate knowledge-acquisition mechanism for unlabelled observations.
