Continual Learning in Practice · Diethe et al. (2019)

When should a model adapt?

Compare six update policies on the same stream. Inspect the evidence, predictions and cost behind each decision.

Experimental application of the paper’s architecture, not a reproduction of a Diethe algorithm. Interactive runs use synthetic feature vectors, not EEG recordings.

01 / Monitoring · §4.1

Did the features change?

PC1 EWMA warnings followed by equal-window Hotelling validation. A relationship change can occur without an input-distribution change.

02 / Policy · §5.2

When should we update?

Never, periodically, on warning, on confirmation, after a drop in labelled accuracy, or using an experimental evidence-value cost policy.

03 / Horizon and cost · §5

Was updating worthwhile?

Compare accuracy gain with update frequency, training-set growth and measured retraining time.

Evidence-value decisions

This experimental heuristic values the estimated reduction in rolling accuracy standard error if more labelled samples arrive, and subtracts sample-acquisition and delay costs. All costs are accuracy-equivalent units, not pounds or actual welfare. It is not an implementation of the 2026 paper's minimax-regret A-value. Evaluation labels are revealed immediately after each prediction. A choice to collect more evidence waits for subsequent normal streaming trials; it does not procure samples or block model predictions.

Current evidence boundary

Implemented: monitoring, labelled prediction tracking, policy-family classification, expanding-data retraining, trials-since-update evidence and event exports. The six-policy laboratory remains a matched comparison rather than a complete continual-learning system. Delayed labels, bounded memory, automatic candidate acceptance and model rollback remain future experiments. Integer classifier versions are audit records, not saved model snapshots.
