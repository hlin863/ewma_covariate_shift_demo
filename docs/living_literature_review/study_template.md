# Study entry template

Copy this structure when integrating a new paper into the living literature
review.

## Citation

Full citation and source location. State whether the source PDF is committed in
`papers/` or tracked externally.

## Research question

What problem does the study ask?

## Published method

Summarise only the components relevant to this repository.

## Repository mapping

| Published component | Repository implementation | Status |
| --- | --- | --- |
| ... | ... | reproduction / paper-inspired / extension / planned |

## Assumptions and ambiguities

Record anything that required an implementation decision because the paper did
not completely specify it.

## Experiments and evidence

List runner commands, output paths, tests and relevant result snapshots.

## Discrepancies

Record where the implementation/result differs from the source and whether the
cause is known, suspected or unresolved.

## Effect on later work

Which later paper, module or repository extension builds on this study?

## Remaining research gap

State the next unresolved question created by this implementation.
